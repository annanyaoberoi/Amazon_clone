# 🛒 Amazon Clone (HTML & CSS)

A front-end clone of the Amazon homepage built using **HTML** and **CSS**.  
This project focuses on replicating the UI design and layout of a modern e-commerce website.

---

## 🚀 Features

- Responsive homepage layout  
- Navigation bar with logo, search bar, and menu  
- Product sections with images and categories  
- Banner/hero section  
- Footer with multiple links  
- Clean and structured UI similar to Amazon  

---

## 🛠️ Tech Stack

- **HTML5** – Structure & Form Components  
- **CSS3** – Styling & layout
